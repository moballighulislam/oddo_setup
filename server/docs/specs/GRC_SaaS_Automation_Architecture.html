Client-side capture

A lightweight JavaScript snippet on every page. Reads URL parameters on load, persists them in a first-party cookie, and injects hidden fields on submit.

// Page load → read UTMs from URL → store in first-party cookie
function captureParams() {
  const params = new URLSearchParams(location.search);
  const keys = ['utm_source','utm_medium','utm_campaign','utm_term','utm_content'];
  keys.forEach(k => {
    const v = params.get(k);
    if (v) setCookie(k, v, 90);
  });
  if (!getCookie('first_touch_src'))
    setCookie('first_touch_src', params.get('utm_source') || 'direct', 90);
}

// Form submit → inject hidden fields → POST
function onSubmit(form) {
  const hidden = {
    ...getAllCookies(),
    page_url: location.pathname,
    referrer_url: document.referrer,
    session_id: getSessionId(),
    form_name: form.dataset.formName,
  };
  Object.entries(hidden).forEach(([k,v]) => {
    const el = document.createElement('input');
    el.type='hidden'; el.name=k; el.value=v||'';
    form.appendChild(el);
  });
}
Cookie strategy: UTM cookies expire at 90 days for multi-touch attribution. Session ID expires on browser close. First-touch source is write-once.

Server validation

Every submission passes through four checks before it touches the CRM.

Email validation

  • Block personal domains (gmail, yahoo, outlook)
  • MX record lookup
  • Disposable email detection

Data enrichment

  • IP → geolocation (MaxMind)
  • Email domain → company data
  • Phone formatting to E.164

Spam / bot detection

  • Honeypot field
  • Submission speed check (<3s = bot)
  • Rate limit: 5 / IP / hour

Deduplication

  • Match key: email address
  • Existing lead → update + log submission
  • New email → create lead
